# サイコロは絶対 — 画面一覧・機能一覧

作成日：2026年10月14日

[要件整理](requirements.md)をもとにした、画面試作に向けた簡易たたき台。画面の分け方や配置は試作で調整する。

## 画面一覧

| ID | 画面 | 主な内容・操作 |
|---|---|---|
| S01 | ログイン | 管理者がMicrosoft Entra IDでログインする。 |
| S02 | ホーム | 新しいゲームを開始する。参加者ごとの累積負け額を確認する。ゲーム履歴は掲載せず、履歴画面への入口を置く。 |
| S03 | 参加者選択 | 固定の名前リストから当日の参加者を選び、ゲームを開始する。 |
| S04 | サイコロ | 参加者ごとの3Dサイコロを表示し、一括または個別に振る。操作待ち・抽選中・同点・敗者確定を表示する。 |
| S05 | 金額確認／結果 | 敗者確定後に会計総額を入力し、各自の負担額と負け額を確認して保存する。参加者・出目・敗者・金額をスクリーンショットで共有しやすく表示する。 |
| S06 | 負け額の履歴／詳細 | ゲーム履歴の一覧と個別詳細で、誰が・いつ・いくら負けたかを確認する。会計総額・各自の負担額も表示する。詳細から履歴を削除できる。 |

基本の流れ：ログイン → ホーム → 参加者選択 → サイコロ → 金額確認／結果。

履歴の確認：ホーム → 負け額の履歴 → 個別詳細 → 削除確認。

## 機能一覧

| ID | 機能 | 概要 | 関連画面 |
|---|---|---|---|
| F01 | 認証・利用制限 | 管理者本人だけが画面とAPIを利用できるようにする。参加者のログインは不要。 | 全画面 |
| F02 | 参加者選択 | あらかじめ用意した固定の名前リストから参加者を選ぶ。 | S03 |
| F03 | ゲーム開始 | 選択した参加者でゲームを作成する。一台のスマートフォンを全員で使う。 | S03 |
| F04 | サイコロ抽選 | 一括・個別の操作に対応する。本番の出目はバックエンドで確定する。 | S04 |
| F05 | 3D表示 | 確定した出目と上面が一致するサイコロアニメーションを表示する。 | S04 |
| F06 | 敗者判定・再抽選 | 全員の出目がそろったら最小出目の一人を敗者とする。最小出目が同点なら全員で振り直す。 | S04 |
| F07 | 会計総額入力 | 会計総額を整数円で入力し、入力値を検証する。 | S05 |
| F08 | 負担額・負け額計算 | 千円単位の基準負担額を算出し、余りを敗者の負け額とする。敗者自身の負担は基準負担額＋負け額。 | S05 |
| F09 | 結果保存 | 日時、参加者、各抽選の出目、敗者、会計総額、各自の負担額、負け額を保存する。 | S05 |
| F10 | 履歴閲覧 | 保存済みゲームの一覧と詳細を認証後に確認する。日時・敗者・負け額を中心に表示する。 | S06 |
| F11 | 累積負け額表示 | 固定参加者全員をホームに表示する。未参加は「—」、参加済みの累積負け額が0円なら「0円」、その他は合計金額を表示する。 | S02 |
| F12 | 共有用の結果表示 | 結果を一枚で把握できるようにし、管理者がスクリーンショットで共有できるようにする。 | S05 |
| F13 | 重複操作・通信失敗への対応 | 抽選や金額登録の重複を防ぎ、通信失敗や再読み込みで確定結果を誤って上書きしないようにする。 | S04・S05 |
| F14 | 履歴削除 | 個別詳細から確認を経て履歴を削除する。削除した履歴の負け額を累積から除外する。削除方式・復元可否・APIは後続で設計する。 | S06 |

## 試作で決めること

- 一括・個別操作の配置と、個別に振った途中で一括操作した場合の挙動。
- 固定参加者のメンバーと、名前の追加・修正方法。
- 会計総額が「参加人数 × 1,000円」未満の場合、0円、金額上限の扱い。
- 中断・再開、金額入力前の保存、保存後の金額訂正、履歴削除方式・復元可否。
- 履歴の並び順。
- アプリからの画像保存・共有ボタンを初期版に含めるか。

参加者ごとの別端末接続、公開履歴、ログイン不要の結果URL、追加統計は初期版の対象外。
